How Does This Percentage Calculator Work?

Enter a number and percentage using the input boxes or sliders. The calculator automatically keeps the slider and number input synchronized.

Percentage Formula

Percentage Value = Number × Percentage ÷ 100

Example

If the number is 500 and the percentage is 10%:

500 × 10 ÷ 100 = 50

  • Percentage Value = 50
  • Addition = 550
  • Subtraction = 450
  • Multiplication = 25,000
  • Division = 10

Percentage Increase

Original Number + Percentage Value.

Percentage Decrease

Original Number − Percentage Value.
